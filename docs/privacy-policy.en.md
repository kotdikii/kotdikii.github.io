# Privacy Policy — DeepCheck

**Effective date:** June 11, 2026

DeepCheck is an app for testing smartphone hardware components (display, sensors, camera, microphone, storage, connectivity, and more). This policy explains what data the app uses and how it is handled.

**In short: DeepCheck does not collect, store on our servers, or share your personal data with anyone. Everything runs locally on your device. The app has no accounts, no ads, no analytics, and sends no data to the internet.**

## 1. Who processes the data

Developer: kotdikii.
Privacy contact: **kotdikii@gmail.com**

## 2. What data the app collects

DeepCheck **does not collect personal data** and does not transmit it anywhere. The app sends no data over the network: it has no server backend, no analytics, no advertising modules, and no crash-reporting services.

To run tests, the app accesses hardware features and system information. This data is processed **on the device only**, in real time, shown to you as a test result, and **never leaves the device**.

## 3. Permissions and why they are needed

| Permission / feature | Purpose | What happens to the data |
|---|---|---|
| Camera | Camera test: live preview and a test photo | The photo is saved to the app's private cache, accessible only to the app, and removed automatically; it is never uploaded |
| Microphone | Microphone / headset test | Audio is analyzed in real time; it is not recorded to a file, stored, or transmitted |
| Location (fine / coarse) | GPS test and Wi-Fi network scanning | Coordinates and the network list are shown on the test screen; not stored or transmitted |
| Phone state | SIM card and connectivity test | Network/SIM info is read to display the result; not stored or transmitted |
| Bluetooth | Bluetooth test | Device discovery to verify the module; data is not stored or transmitted |
| Wi-Fi & network, nearby devices | Wi-Fi / connectivity tests | Network state is read to display the result; not stored or transmitted |
| NFC | NFC test | Checks presence and operation of the module; data is not stored |
| All files access | Storage speed test, including external USB-OTG and SD media | The app creates a temporary file on the drive you select, measures speed, and deletes it. The app **does not read, collect, or transmit your personal files** |
| Modify system settings | Screen brightness test | Temporarily changes brightness during the test and restores the previous value |
| Biometrics (fingerprint) | Fingerprint sensor test | Verifies the sensor via Android; the app **has no access** to your biometric data |
| Sensors, vibration, etc. | Corresponding hardware tests | Readings are used only to display the test result |

## 4. Data storage

Test results and measurement history (if you choose to save them) are stored **locally on your device**. Temporary files (such as the camera test photo or the storage benchmark file) are created in the app's private storage and deleted. Uninstalling the app removes all data associated with it.

## 5. Sharing with third parties

There is none. DeepCheck does not share data with third parties, does not use third-party analytics/advertising SDKs, and sends no data to the internet.

## 6. Children

The app is not intended to collect data from children and does not collect personal data at all.
