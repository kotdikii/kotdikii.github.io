# Política de privacidad — DeepCheck

**Fecha de entrada en vigor:** 11 de junio de 2026

DeepCheck es una aplicación para el diagnóstico de los componentes de hardware de un smartphone (pantalla, sensores, cámara, micrófono, almacenamiento, conectividad, etc.). Esta política describe qué datos utiliza la aplicación y cómo los trata.

**En resumen: DeepCheck no recopila, no almacena en nuestros servidores ni transmite a terceros tus datos personales. Todo se realiza localmente en el dispositivo. La aplicación no tiene cuentas, no tiene publicidad, no tiene analíticas y no transmite datos a internet.**

## 1. Quién trata los datos

Desarrollador: kotdikii.
Contacto para cuestiones de privacidad: **kotdikii@gmail.com**

## 2. Qué datos recopila la aplicación

DeepCheck **no recopila datos personales** ni los transmite a ningún sitio. La aplicación no envía datos a la red: no tiene backend de servidor, analíticas, módulos publicitarios ni sistemas de recopilación de fallos.

Para realizar las pruebas, la aplicación accede a funciones de hardware e información del sistema. Estos datos se procesan **únicamente en el dispositivo**, en tiempo real, se te muestran como resultado de la prueba y **no salen del dispositivo**.

## 3. Permisos y para qué son necesarios

| Permiso / función | Para qué se usa | Qué ocurre con los datos |
|---|---|---|
| Cámara | Prueba de cámara: vista previa y foto de prueba | La foto se guarda en la caché interna de la aplicación, solo es accesible para la aplicación y se elimina automáticamente; no se envía a ningún sitio |
| Micrófono | Prueba de micrófono/auriculares | El sonido se analiza en tiempo real; no se graba en un archivo, no se guarda y no se transmite |
| Ubicación (precisa/aproximada) | Prueba de GPS y escaneo de redes Wi-Fi | Las coordenadas y la lista de redes se muestran en la pantalla de la prueba; no se guardan ni se transmiten |
| Estado del teléfono | Prueba de tarjeta SIM y conectividad | La información de red/SIM se lee para mostrar el resultado; no se guarda ni se transmite |
| Bluetooth | Prueba de Bluetooth | Búsqueda de dispositivos para comprobar el módulo; los datos no se guardan ni se transmiten |
| Wi-Fi y red, dispositivos cercanos | Pruebas de Wi-Fi/conectividad | El estado de la red se lee para mostrar el resultado; no se guarda ni se transmite |
| NFC | Prueba de NFC | Comprobación de la presencia y el funcionamiento del módulo; los datos no se guardan |
| Acceso a todos los archivos (All files access) | Prueba de velocidad de almacenamiento, incluidos USB-OTG y SD externos | La aplicación crea un archivo temporal en el almacenamiento que elijas, mide la velocidad y lo elimina. La aplicación **no lee, no recopila ni transmite tus archivos personales** |
| Modificar ajustes del sistema | Prueba de brillo de la pantalla | Cambia temporalmente el brillo durante la prueba y restaura el valor anterior |
| Biometría (huella) | Prueba del sensor de huella | Comprobación del funcionamiento del sensor mediante Android; la aplicación **no accede** a tus datos biométricos |
| Sensores, vibración, etc. | Pruebas de hardware correspondientes | Las lecturas se usan únicamente para mostrar el resultado de la prueba |

## 4. Almacenamiento de datos

Los resultados de las pruebas y el historial de mediciones (si los guardas) se almacenan **localmente en tu dispositivo**. Los archivos temporales (por ejemplo, la foto de prueba de la cámara o el archivo del benchmark de almacenamiento) se crean en el almacenamiento privado de la aplicación y se eliminan. Al desinstalar la aplicación se borran todos los datos asociados a ella.

## 5. Transmisión de datos a terceros

No hay ninguna transmisión. DeepCheck no transmite datos a terceros, no utiliza SDK de terceros de analíticas/publicidad y no envía tus datos personales a internet.

## 6. Compras

La aplicación puede tener funciones de pago. El pago lo procesa la tienda a través de la cual instalaste la aplicación (Google Play, RuStore o Huawei AppGallery), según las normas de esa tienda. El procesamiento del pago y los datos de tu tarjeta los realiza la tienda; la aplicación **no los recibe ni los almacena**. La aplicación no tiene servidor propio, por lo que no recopila ni transmite a ningún sitio datos sobre tus compras; el hecho de la compra se usa solo en el dispositivo para desbloquear las funciones de pago. Los reembolsos y las cuestiones de pago se rigen por las normas de la tienda correspondiente.

## 7. Menores

La aplicación no está destinada a recopilar datos de menores y, en general, no recopila datos personales.
