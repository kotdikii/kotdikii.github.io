# Политика конфиденциальности — DeepCheck

**Дата вступления в силу:** 11 июня 2026 г.

DeepCheck — приложение для диагностики аппаратных компонентов смартфона (экран, датчики, камера, микрофон, накопитель, связь и др.). Настоящая политика описывает, какие данные приложение использует и как с ними обращается.

**Коротко: DeepCheck не собирает, не хранит на наших серверах и не передаёт третьим лицам ваши персональные данные. Всё выполняется локально на устройстве. У приложения нет аккаунтов, нет рекламы, нет аналитики и нет передачи данных в интернет.**

## 2. Какие данные приложение собирает

DeepCheck **не собирает персональные данные** и не передаёт их куда-либо. Приложение не отправляет данные в сеть: в нём нет серверного бэкенда, аналитики, рекламных модулей и систем сбора сбоев.

Для проведения тестов приложение получает доступ к аппаратным функциям и системной информации. Эти данные обрабатываются **только на устройстве**, в реальном времени, отображаются вам как результат теста и **не покидают устройство**.

## 3. Разрешения и зачем они нужны

| Разрешение / функция | Зачем используется | Что происходит с данными |
|---|---|---|
| Камера | Тест камеры: предпросмотр и пробный снимок | Снимок сохраняется во внутренний кэш приложения, доступен только приложению и автоматически удаляется; никуда не отправляется |
| Микрофон | Тест микрофона/гарнитуры | Звук анализируется в реальном времени; не записывается в файл, не сохраняется и не передаётся |
| Геолокация (точная/приблизительная) | Тест GPS и сканирование Wi-Fi-сетей | Координаты и список сетей показываются на экране теста; не сохраняются и не передаются |
| Состояние телефона | Тест SIM-карты и связи | Информация о сети/SIM считывается для показа результата; не сохраняется и не передаётся |
| Bluetooth | Тест Bluetooth | Поиск устройств для проверки модуля; данные не сохраняются и не передаются |
| Wi-Fi и сеть, ближайшие устройства | Тесты Wi-Fi/связи | Состояние сети считывается для показа результата; не сохраняется и не передаётся |
| NFC | Тест NFC | Проверка наличия и работы модуля; данные не сохраняются |
| Доступ ко всем файлам (All files access) | Тест скорости накопителя, включая внешние USB-OTG и SD | Приложение создаёт временный файл на выбранном вами накопителе, измеряет скорость и удаляет его. Приложение **не читает, не собирает и не передаёт ваши личные файлы** |
| Изменение системных настроек | Тест яркости экрана | Временно меняет яркость во время теста и восстанавливает прежнее значение |
| Биометрия (отпечаток) | Тест сканера отпечатка | Проверка работы датчика средствами Android; приложение **не получает доступ** к вашим биометрическим данным |
| Датчики, вибрация и пр. | Соответствующие аппаратные тесты | Показания используются только для отображения результата теста |

## 4. Хранение данных

Результаты тестов и история измерений (если вы их сохраняете) хранятся **локально на вашем устройстве**. Временные файлы (например, тестовый снимок камеры или файл бенчмарка накопителя) создаются в приватном хранилище приложения и удаляются. Удаление приложения стирает все связанные с ним данные.

## 5. Передача данных третьим лицам

Никакой передачи нет. DeepCheck не передаёт данные третьим сторонам, не использует сторонние SDK аналитики/рекламы и не отправляет данные в интернет.
